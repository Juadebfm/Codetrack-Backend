# Easy backend words

| Word | Simple meaning |
| --- | --- |
| Backend | The server-side part of an app. It handles trusted work and data. |
| Server | A computer program that waits for requests and sends answers. |
| API | A set of URLs that another app can ask for data or actions. |
| Request | A message sent to the backend. Example: “Please log me in.” |
| Response | The backend’s answer to a request. |
| Route | The request method and URL a backend understands. Example: `POST /login`. |
| Controller | A function that handles the steps for one route. |
| Model | The rules for one type of saved data, such as a user or goal. |
| Database | The place where information is saved for later. |
| MongoDB | The database we will use for this project. |
| JSON | A simple text format for sending data. |
| Middleware | A small check that runs before a controller. |
| Password hash | A safe scrambled version of a password. We save this, not the real password. |
| Cookie | Small browser storage that can help a user stay signed in. |
| Environment variable | A private setting kept outside normal code. |

Do not worry about memorising these words. We will use them many times while building.
