# Tools we will use

We will add tools only when they solve a real problem.

| Tool | What it will help us do |
| --- | --- |
| Node.js | Run JavaScript outside the browser. |
| Express | Receive web requests and send web responses. |
| MongoDB | Save users, logs, and goals. |
| Mongoose | Describe MongoDB data with JavaScript models. |
| Mailtrap | Safely practise sending emails. |
| bcryptjs | Turn passwords into password hashes before saving them. |
| JSON Web Token | Help the backend know which user is signed in. |
| cookie-parser | Read login cookies sent by a browser. |
| dotenv | Read private values from a local `.env` file. |
| ESLint | Point out common JavaScript mistakes. |
| Vitest and Supertest | Check that our routes work as expected. |

## Why not add every package now?

Extra packages create extra things to learn and maintain. We will install a package only when the next class step needs it. When we add one, we will explain what it does first.
